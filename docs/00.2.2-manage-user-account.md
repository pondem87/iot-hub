# Use case 2: Manage user account

## use case 2.1: Create user account

#### 1. Intent
- Add a new user to a hub account

#### 2. Primary Actor
- User account owner (human owner)

#### 3. Aggregate root
- Account/User

#### 4. Preconditions
- valid user name
- valid user phone number is valid
- valid password
- valid invitation to an account

#### 5. Command/Inputs
- JoinHubAccountCommand
    - phone number
    - user name
    - password
    - invitation id

#### 6. State changes
- new user created
- invitation accepted
- user verification pending
- verification code generated

#### 7. Invariants
- user must not already exist
- userId is unique and valid phone number
- hub account must be active

#### 8. Domain Events
- InvitationAcceptedEvent
- UserCreatedEvent

#### 9. Side effects
- send verification code
- send welcome message

#### 10. Failure modes
- UserAlreadyExists
- InvalidUserIdentity
- InvalidPasswordFormat
- InvalidInvitation
- AccountNotActive

#### 11. Variants

## use case 2.3: Change user password

#### 1. Intent
- user changing their account password

#### 2. Primary Actor
- User account owner (human owner)

#### 3. Aggregate root
- Account/User

#### 4. Preconditions
- logged-in user must be the same as the user being updated
- user account must be active and verified
- valid new password
- valid old password

#### 5. Command/Inputs
- JoinHubAccountCommand
    - phone number
    - user name
    - password
    - invitation id

#### 6. State changes
- password updated

#### 7. Invariants
- user must be active and verified
- new password must be valid
- old password must be correct

#### 8. Domain Events

#### 9. Side effects
- send password change notification

#### 10. Failure modes
- InvalidPasswordFormat
- AccountNotActive
- IllegalUserAccountState
- InvalidOldPassword

#### 11. Variants
- change password with reset code without old password
    - preconditions:
        - user account must be active but not necessarily verified
        - valid password reset code
        - valid new password
- failure modes for reset code flow:
    - InvalidPasswordResetCode
    - ExpiredPasswordResetCode
